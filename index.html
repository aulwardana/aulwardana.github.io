Research · Open Source · IoT Middleware

MQTT-AC

MQTT-AC is my master thesis project, focused on developing an access control middleware for secure device-to-cloud communication in Internet of Things (IoT) environments using the MQTT protocol. The system provides authentication and authorization for IoT nodes and gateways through an authentication server, secures publish/subscribe communication using SSL/TLS, and is designed for fog computing architectures to ensure trusted sensing data transmission between devices and cloud services.

Golang MQTT Redis PostgreSQL Arduino OpenSSL

Open Source · IoT Platform

UMM Energy

UMMEnergy is my bachelor final project and also my first open-source project. The project focuses on monitoring electrical power generated by a micro-hydro power plant through IoT and open-source hardware technologies, while giving me hands-on experience in system design, software and hardware integration, real-time monitoring, and open-source development practices.
